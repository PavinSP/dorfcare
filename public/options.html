Decision 1

Bringing Maria, the volunteers and the doctor to life as agents

The goal: press "Play" and the personas act on their own. Maria asks for help, Thomas declines because he is at work, Anna accepts and drives over, Gertrud chats with Clara, and the coordinator reacts. The presenter just narrates.

A · Story mode (scripted autopilot)

Recommended for stage

A timed script drives the real app actions across all open windows. Each persona speaks its line in its own browser voice, and the map, ratings and dashboard update live.

Time ~45 min, 1 personCost freeNeeds nothing, works offlineRisk very low, same every run

B · AI persona agents (Claude)

Stretch goal

Each persona gets a profile (age, job, schedule, mood). On every event the app asks Claude what that persona would do and say, as a structured answer such as "accept" or "decline: at work until 17:00". The app then runs that action. Runs differ each time, which feels alive.

  • The API key must stay on a small local server (a Vite middleware route), never in the browser.
  • Single Claude API calls with structured output; our own simulation loop decides when each persona acts.
  • Falls back to Story mode if the network or key fails.
Time ~1.5 h, 1–2 peopleCost cents per runNeeds Anthropic API keyRisk 2–5 s per decision, Wi-Fi

C · A separate voice agent per persona (ElevenLabs)

Not advised today

One ElevenLabs agent per persona talking to each other. A live agent session expects a microphone, so agents can't easily talk to each other on stage. ElevenLabs' built-in "simulated user" is text-only, and its endpoint is marked deprecated with a removal date of 31 Oct 2026, which has passed. A cheaper version: use ElevenLabs text-to-speech only to give A or B distinct, realistic voices.

Time 2 h+Needs ElevenLabs API key on a serverRisk high

Suggested plan: build A now so the demo can't fail, then add B for volunteer decisions only if time remains.

Pitfalls to design around

  • Too few volunteers. A UK phone-friendship trial closed early because it couldn't recruit and keep volunteers. Keep tasks small, cap requests per helper, keep a paid coordinator. source
  • Money can push out goodwill. Keep rewards modest and framed as thanks; use §45b for real payment.
  • Digital exclusion. 42% of people 78+ use a smartphone and 58% lack basic digital skills. Voice or landline check-ins, and family or the nurse as proxy users. source
  • Pilots die when funding ends (Medibus ended; AGnES fees were cut). Tie the business model to existing funding: §45b, Gemeinde programmes, GP contracts.
  • Regulation and liability. Build §45b rules and insurance checks into onboarding; it becomes a selling point to the Landkreis.
  • Thin evidence. Claim "safer, less lonely, faster help", not "saves hospital costs". Frome is the one strong admissions result.
  • Ratings of vulnerable people. Our resident ratings stay coordinator-only and never limit access to emergency or medical help; a low score triggers a friendly call.
